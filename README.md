# Portfolio Milestone — Accessibility & Designed

## 1. Wave Audit
* Added <fieldset> and <legend> to form controls in about.html and index.html.
* Added <label for="..."> tags linked to input IDs to ensure screen reader accessibility.
* Corrected heading hierarchy in project.html by using <h2>.
* Removed syntax errors and empty tags on project templates.
* Added accessible submit buttons and semantic links.

## 2. Gestalt Principles
* Grouped project's title, description, and details inside isolated "(<article>)" with defined margins to visually separate distinct projects.
* Applied uniform background colors, typography, borders, and button styling across all pages to create a cohesive layout.

## 3. Color Palette Consistency
* Body Background: lightgray (#D3D3D3)
* Body Text: black (#000000) — Passes WCAG AA contrast (8.2:1 ratio)
* Header Background: navy (#000080)
* Header Text: white (#FFFFFF) — Passes WCAG AA contrast (16:1 ratio)
